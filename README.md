# Mike Angelo A. Rubia — Portfolio

A minimal, responsive React + Vite portfolio inspired by the clean engineer-first structure of iging.tech, but redesigned around Mike Rubia's freelance/business positioning.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Main files

- `src/main.jsx` — portfolio content and components
- `src/styles.css` — visual system, responsiveness, theme support and project mockups
- `index.html` — metadata and page shell

## Customize next

Replace or expand project descriptions, add real screenshots/live URLs, and update the contact email/social links if needed.
